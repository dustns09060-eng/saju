- 아래 데이터 값만 근거로 하되, **한자·전문용어(기신·삼합·합충·득령 등)를 쓰지 않습니다.** 꼭 필요하면 괄호로 아주 쉽게 풀어 씁니다.
- **누구에게나 맞는 말 금지**: "겉과 속이 다르다 / 완벽주의 / 인정받고 싶어한다 / 생각이 많다 / 예민하다" 류 성격 일반론을 쓰지 않습니다.
- 각 문장은 데이터에 근거하되, 읽는 사람은 명리를 모른다고 생각하고 일상어로.
- 겁주지 않고, 의료·임신·수명은 단정하지 않습니다.
